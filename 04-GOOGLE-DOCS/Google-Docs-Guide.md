## 01. INTRODUCTION

Google Docs is an online word processor developed by Google.

It allows users to:
- Create documents.
- Edit existing documents.
- Format text and paragraphs.
- Collaborate in real time.
- Store documents online.
- Share documents with others.

Official website:

https://docs.google.com/

## 02. FEATURES

- Cloud-based document storage.
- Automatic saving.
- Real-time collaboration.
- Comments and suggestions.
- Version history.
- Templates.
- Voice typing.
- Spell checking.
- Offline editing when enabled.
- Export to different file formats.

## 03. CREATING A DOCUMENT

Steps:

1. Open Google Docs.
2. Sign in with a Google account.
3. Select Blank Document or a template.
4. Enter the document title.
5. Start writing.
6. Changes are automatically saved.

## 04. TEXT FORMATTING

Common formatting options:

| Feature | Function |
|---|---|
| Bold | Makes text darker |
| Italic | Slants text |
| Underline | Adds a line below text |
| Font | Changes text typeface |
| Font Size | Changes text size |
| Font Colour | Changes text colour |
| Highlight | Highlights text |
| Strikethrough | Draws a line through text |

Useful shortcuts:

- Bold: `Ctrl/Cmd + B`
- Italic: `Ctrl/Cmd + I`
- Underline: `Ctrl/Cmd + U`

## 05. PARAGRAPH FORMATTING

Paragraph formatting controls how text is arranged.

Features include:

- Left alignment.
- Centre alignment.
- Right alignment.
- Justified alignment.
- Line spacing.
- Paragraph spacing.
- Indentation.

## 06. HEADINGS AND STYLES

Google Docs provides predefined text styles.

Common styles:

- Normal text
- Title
- Subtitle
- Heading 1
- Heading 2
- Heading 3

Styles maintain consistent formatting and help create an automatic table of contents.

## 07. PAGE SETUP

Page setup allows users to customise:

- Paper size.
- Page orientation.
- Page margins.
- Page colour.

Common orientations:

- Portrait.
- Landscape.

Access through:

**File → Page setup**

## 08. LISTS

Google Docs supports:

**Bulleted lists**
- First point
- Second point

**Numbered lists**
1. First step
2. Second step

Multilevel lists can be used to organise nested information.

## 09. TABLES

Tables organise information in rows and columns.

To insert:

**Insert → Table**

Users can:
- Add and remove rows.
- Add and remove columns.
- Resize cells.
- Change borders.
- Change cell colours.
- Align cell contents.

## 10. IMAGES AND DRAWINGS

Images can be added through:

**Insert → Image**

Available image sources may include:
- Computer uploads.
- Google Drive.
- Google Photos.
- Web search.

Image layout options include:
- In line with text.
- Wrap text.
- Break text.
- Behind text.
- In front of text.

Drawings can be created through:

**Insert → Drawing**

## 11. HYPERLINKS

Hyperlinks connect text to websites, documents or other destinations.

Shortcut:

`Ctrl/Cmd + K`

Steps:

1. Select the text.
2. Open Insert Link.
3. Enter the URL.
4. Click Apply.

## 12. HEADERS AND FOOTERS

Headers appear at the top of pages.

Footers appear at the bottom of pages.

Access through:

**Insert → Page elements → Header and footer**

They can contain:
- Document titles.
- Author names.
- Dates.
- Page information.

## 13. PAGE NUMBERS

Page numbers help organise long documents.

Access through:

**Insert → Page elements → Page number**

Different page numbering options are available.

## 14. TABLE OF CONTENTS

A table of contents provides navigation through a long document.

Steps:

1. Apply heading styles to sections.
2. Place the cursor where the contents should appear.
3. Open Insert.
4. Select Table of contents.
5. Choose a suitable style.
6. Update it when headings change.

## 15. COLLABORATION

Google Docs supports real-time collaboration.

Multiple people can:
- Edit the same document.
- View changes.
- Communicate through comments.
- Suggest modifications.

## 16. COMMENTS AND SUGGESTIONS

**Comments:**

Used to provide feedback without directly changing the document.

**Suggestion mode:**

Allows users to propose edits that can be accepted or rejected.

Users can access these features through the editing mode menu and comment tools.

## 17. VERSION HISTORY

Version history tracks previous document versions.

Access through:

**File → Version history → See version history**

Features:
- View previous versions.
- Identify changes.
- Restore an earlier version.
- Name important versions.

## 18. SHARING AND PERMISSIONS

Google Docs offers sharing controls.

Common roles:

| Role | Permission |
|---|---|
| Viewer | Can view |
| Commenter | Can comment |
| Editor | Can edit |

Users can share through:
- Specific email addresses.
- Restricted links.
- General access links, depending on settings.

Always check permissions before sharing.

## 19. EXPORTING DOCUMENTS

Google Docs supports downloading documents in several formats.

Common formats:

- Microsoft Word (.docx)
- PDF (.pdf)
- Plain Text (.txt)
- Rich Text Format (.rtf)
- OpenDocument Format (.odt)
- HTML (.html)

Access through:

**File → Download**

## 20. USEFUL KEYBOARD SHORTCUTS

| Shortcut (Mac) | Function |
|---|---|
| Cmd + B | Bold |
| Cmd + I | Italic |
| Cmd + U | Underline |
| Cmd + K | Insert link |
| Cmd + Z | Undo |
| Cmd + Shift + Z | Redo |
| Cmd + F | Find |
| Cmd + P | Print |
| Cmd + A | Select all |
| Cmd + Enter | Page break |

Some shortcuts may vary depending on browser and operating system.
